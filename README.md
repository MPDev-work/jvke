# Jvke — Portfolio

A dark editorial developer portfolio built with React, Vite, and Tailwind CSS v4.

## Setup

npm install
npm run dev

Open the printed local URL (usually http://localhost:5173).

## Build for production

npm run build

Output goes to dist/, ready to deploy to Vercel, Netlify, or any static host.

## Before deploying

- src/components/Contact.jsx — replace the placeholder email, GitHub, and LinkedIn links with your real ones.
- src/data/projects.js — update project descriptions or add screenshots if you want real imagery instead of the abstract placeholder patterns.
- public/favicon.svg — swap for your own mark if you have one.
